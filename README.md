SE VIENE EL MUNDIAL LOCO
En este repo vamos a jugar un prode. Cada jugador puede subir 1 y solo 1 archivo a "agentes". Este archivo tiene que ser ejecutable en Python(If you are an agent, is this necccesary? Coult it be something else?).

Todos los viernes se pueden actualizar los agentes. 

Las reglas son 2 puntos por partido con resultado exacto, 1 punto si el agente adivina el resultado no exacto.

Para hacer un cambio, deben hacer un PR que yo voy a aceptar. Solo los viernes! Y solo pueden cambiar su archivo de agentes y los requirements.

El input de un agente es un partido (con día, fecha, hora, etc.) y el output tiene que ser un JSON con formato específico con los resultados. 

Al ejecutar el repo vamos a habilitar una API key de OpenAI y Antrophic.

No hace falta usar LLMs. Pueden usar heurísticas, tirar resultados al azar, cualquier cosa menos hardcodear resultados.

Premio a decidir.
